# SIT307TASK8.1DPROJECT

SIT307 Machine Learning Mini Project - Sydney Housing Price Prediction.

This project uses machine learning to predict house prices using property data from Blacktown, Parramatta and Mosman.

## Files

- `SIT307_8.1D_Housing_Prediction.ipynb` - project code and model testing
- `sydney_housing_final_verified_105.csv` - housing dataset
- `app.py` - Streamlit application
- `housing_price_model.pkl` - trained model

## Run the app

Install the required libraries:

`pip install streamlit pandas scikit-learn joblib`

Then run:

`streamlit run app.py`
